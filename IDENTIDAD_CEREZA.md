# 🍒 IDENTIDAD VISUAL: TEMPORADA DE CEREZAS

**Misión:** Crear invitaciones digitales que se sientan como regalos de lujo. Ser el gancho para servicios de eventos premium.

## Paleta de Colores Base
* **Cereza Profundo (Primary):** #990033 (Para acentos fuertes, botones de lujo)
* **Rosa Cereza Suave (Secondary):** #FFCCD5 (Para fondos, brillos de cristal)
* **Dorado/Crema (Accent):** #F4E1C1 (Para tipografía elegante y bordes)
* **Cristal Oscuro (Glass):** rgba(30, 0, 10, 0.6) con desenfoque (blur).

## Tecnología Clave
* No usar PDFs estáticos. Todo debe ser HTML interactivo.
* Animaciones fluidas (GSAP) para dar sensación "premium".
* Prioridad móvil (Mobile First): Se diseñan para verse increíbles en celular.
